基于低代码可视化开发理念，搭建在线表单设计平台，支持拖拽式表单搭建、自定义属性配置与数据收集，无需代码即可快速制作各类业务表单，适配多场景数据采集需求。

**详细功能需求**：内置输入框、单选、多选、日期、文件上传等常用表单组件，支持自由拖拽布局、组件嵌套排版。可自定义组件属性、表单校验规则，支持实时预览表单效果，表单模板可保存复用。前端支持用户在线填写、提交表单，后台可汇总、检索、导出表单数据，快速适配报名、调研、登记等各类数据收集场景。

**技术要求**：Go Gin实现表单模板存储、数据接收、规则校验、数据统计接口；Vue3实现组件拖拽布局、属性双向绑定、动态表单渲染等高难度低代码交互；SQLite存储表单模板与填写数据；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接编译运行。
