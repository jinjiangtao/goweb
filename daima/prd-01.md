在线代码片段分享系统

**总体功能**：面向开发人员日常代码管理与复用需求，打造在线代码编辑、存储与分享平台，集成多语言编辑、代码格式化、片段管理及社交互动功能，提升开发效率。

**详细功能需求**：支持主流编程语言在线编辑，自带语法高亮、自动缩进、一键格式化功能。用户可创建公开、私密两种权限的代码片段，支持代码差异对比、一键复制复用。平台提供片段点赞、收藏、评论互动功能，搭配关键词检索、分页加载功能，方便开发人员快速查找、管理和复用优质代码片段。

**技术要求**：Go Gin实现代码片段存储、权限管控、互动数据统计、检索接口；Vue3集成高端在线编辑器，实现代码高亮、格式化、差异对比等高交互功能；SQLite存储代码片段及用户操作数据；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接编译运行。
