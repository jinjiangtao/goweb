## 现在的开发任务：开发租房信息发布系统的「后台管理端」，支持管理员发布和管理房屋信息

## 技术栈：
- 后端：Go + Gin + GORM + SQLite
- 前端：Vue3 + Element Plus + Vite
- 认证：JWT

## 项目结构：
```

server/                    # API 接口服务
admin/                     # 后台管理前端

```

## 功能需求：

### 一、管理员认证模块
- 管理员通过用户名+密码登录，登录成功返回认证凭证
- 未登录状态下无法访问任何管理页面，自动跳转到登录页
- 点击退出按钮清除认证信息并跳转登录页
- 登录后可修改密码

### 二、房源管理模块

#### 2.1 房源列表
- 以表格形式展示所有房源
- 表格包含：房源ID、标题、小区名称、区域、户型、面积、租金、状态（上架/下架）、是否推荐、发布时间、操作按钮
- 支持分页展示
- 支持搜索筛选：按标题模糊搜索、按小区名称模糊搜索、按状态下拉筛选、按是否推荐筛选
- 状态用不同颜色的标签显示（上架=绿色，下架=灰色）

#### 2.2 发布房源
点击「发布房源」按钮弹出表单，需要填写以下信息：

**基本信息**：
- 标题（必填）、小区名称（必填）、区域（必填，下拉选择）、详细地址（必填）
- 户型（必填）、面积（必填）、租金（必填）
- 楼层（选填）、朝向（选填）、装修（选填，下拉）

**详情信息**：
- 配套设施（多选框：WiFi、空调、冰箱、洗衣机、暖气等）
- 房源描述（必填）、联系人（必填）、联系电话（必填）

**图片上传**：
- 支持上传多张房源图片（至少1张，最多9张）
- 支持拖拽排序、删除
- 第一张图片自动作为封面图

#### 2.3 编辑房源
- 点击「编辑」按钮，弹出表单并回填所有已有信息
- 可修改所有字段，图片可增删改

#### 2.4 删除房源
- 点击「删除」按钮，弹窗二次确认，软删除

#### 2.5 上下架
- 列表中有「上架/下架」切换按钮

#### 2.6 推荐设置
- 列表中有一键设置/取消「推荐」功能

### 三、后端要求（server 目录）
- 实现管理员认证相关接口（登录、退出、获取个人信息、修改密码）
- 实现房源管理相关接口（列表、详情、发布、编辑、删除、上下架、推荐设置）
- 实现图片上传接口
- 使用 SQLite 数据库
- 默认创建管理员账号 admin / 123456
- 图片上传到 server/uploads/ 目录

### 四、前端要求（admin 目录）
- 登录页面：用户名+密码表单
- 后台主布局：左侧侧边栏（房源管理菜单）+ 右侧内容区
- 房源列表页：搜索筛选区、表格、分页、操作按钮
- 房源表单弹窗：包含所有字段、图片上传组件、表单验证
- 路由守卫：未登录跳转登录页
- 使用 Pinia 管理登录状态和 Token

### 五、输出要求
- 按 server/ 和 admin/ 目录结构输出完整代码
- 每个文件标注相对于项目根目录的路径
- 代码可直接运行， 前后端正常启动， 登录后可正常操作所有功能
