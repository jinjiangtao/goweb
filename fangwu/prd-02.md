## 任务：熟悉现在的功能需求，为租房信息发布系统开发「前台展示端」的房源列表页和详情页

## h5端代码放到web 目录下， 新建一个目录，目录名是web。
## 技术栈：
- Vue3 + Vite
- 状态管理：Pinia
- HTTP请求：Axios
- 样式：普通CSS或SCSS（不使用UI组件库，纯手写样式，适配移动端+PC端）


## 功能需求：
### 一、房源列表页
**页面位置**：首页（路径 `/`）

#### 1.1 顶部搜索区
- **搜索框**：输入关键词（标题、小区名称），点击搜索按钮或回车触发搜索
- **筛选条件**（一行或两行展示）：
  - 区域下拉筛选（全部/朝阳区/海淀区/丰台区等）
  - 户型下拉筛选（全部/1室/2室/3室/4室+）
  - 租金区间下拉筛选（全部/1000-2000/2000-4000/4000-6000/6000以上）
- **排序方式**：最新发布 / 价格低到高 / 价格高到低
- **搜索/重置按钮**：点击搜索执行筛选，点击重置清空所有条件

#### 1.2 房源列表
- 以卡片网格形式展示房源（每行2-4列，响应式）
- 每个房源卡片包含：
  - 封面图（顶部，占满宽度）
  - 标题（一行，超出省略号）
  - 小区名称 + 区域
  - 户型 + 面积
  - 租金（突出显示，红色/加粗）
  - 标签（如：推荐、新上、近地铁等，如有数据）
- 卡片点击后跳转到详情页

#### 1.3 分页
- 底部显示分页组件
- 包含：上一页、页码、下一页、每页条数选择

#### 1.4 空状态
- 无房源时显示友好提示：「暂无房源，请稍后再来」

#### 1.5 加载状态
- 数据加载中显示骨架屏或加载动画

### 二、房源详情页

**页面位置**：路径 `/detail/:id`

#### 2.1 图片轮播
- 顶部展示房源图片轮播
- 支持左右滑动切换
- 底部显示小圆点指示当前图片位置
- 如只有一张图片，不显示轮播箭头

#### 2.2 房源基本信息
- 标题（大号加粗）
- 租金（大号红色突出显示，标注“元/月”）
- 标签行：户型 | 面积 | 楼层 | 朝向 | 装修
- 区域 + 详细地址

#### 2.3 配套设施
- 以图标+文字标签形式展示（如：WiFi、空调、冰箱、洗衣机、暖气等）
- 有则高亮显示，无则灰色显示

#### 2.4 房源描述
- 展示详细描述文本

#### 2.5 联系房东
- 联系人：显示姓名
- 联系电话：默认隐藏（部分号码用*代替），点击「显示号码」按钮后完整显示
- 点击「显示号码」时，如已登录直接显示，未登录跳转登录页
- 显示号码同时记录一条咨询记录（调用后端接口）

#### 2.6 浏览量
- 页面底部显示浏览次数

#### 2.7 返回列表
- 顶部有返回按钮，点击回到列表页

#### 2.8 推荐房源（如接口支持）
- 详情页底部展示「推荐房源」区域
- 横向滚动展示3-5个推荐房源卡片

### 三、接口对接要求

#### 3.1 列表页接口
| 用途 | 说明 |
|------|------|
| 获取房源列表 | 传入分页参数、搜索关键词、筛选条件、排序方式 |
| 获取筛选选项 | 获取区域列表、户型列表等（可从列表接口返回或单独接口） |

#### 3.2 详情页接口
| 用途 | 说明 |
|------|------|
| 获取房源详情 | 传入房源ID，返回完整房源信息 |
| 记录咨询 | 传入房源ID，记录一次咨询（显示号码时调用） |
| 获取推荐房源 | 传入房源ID，返回相关推荐房源列表 |

### 四、UI/UX 要求
- 整体风格：简洁、清爽、适合租房场景（推荐暖色）
- 移动端优先：在手机上显示效果良好，同时适配平板和PC
- 卡片间距舒适，视觉层次清晰
- 租金、标题等重点信息突出
- 所有交互有反馈（点击、加载、错误提示）

### 五、输出要求
代码可以直接运行， 代码质量要求高，符合 Vue3 + Vite 项目规范。
