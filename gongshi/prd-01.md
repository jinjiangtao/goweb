面向企业员工工时数字化管理场景，搭建线上工时填报与统计系统，结合日历交互、数据校验、审核流程，实现工时填报、审核、数据统计全流程线上化管理。

**详细功能需求**：员工可通过日历视图按日、按周快捷填报工时，关联对应项目与工作内容。系统自动校验工时数据合规性，拦截重复、异常填报数据。前端通过图表可视化汇总工时数据，支持明细弹窗预览查看。后台管理人员可审核、驳回工时单据，支持历史填报记录追溯查询，实现企业工时规范化统计管理。

**技术要求**：Go Gin实现工时数据校验、审核流程、数据汇总统计接口；Vue3实现日历快捷填报、数据联动校验、可视化汇总等高难度交互；SQLite存储项目信息与工时审核记录；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接运行。
