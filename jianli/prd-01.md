面向用户简历快速制作需求，开发可视化在线简历编辑系统，依托模板套用、拖拽排版、实时预览功能，实现零基础快速制作、导出专业简历。

**详细功能需求**：系统内置多套通用专业简历模板，支持用户自定义增删简历模块，拖拽调整模块排序布局。可在线编辑文字内容、调整样式格式，页面实时渲染预览制作效果。系统自动保存多版本简历，支持版本自由切换，一键导出PDF格式简历文件，满足求职简历制作与修改需求。

**技术要求**：Go Gin实现简历数据存储、版本管理、PDF文件导出接口；Vue3实现模块拖拽排版、样式编辑、实时预览等高难度前端交互；SQLite存储简历模板与用户简历数据；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接运行。
