交互式日程日历管理系统

面向个人日常时间规划与日程管理需求，开发高交互日历日程系统，依托拖拽编辑、动态渲染、智能提醒功能，实现日程高效管理，解决时间规划混乱问题。

**详细功能需求**：提供月、周、日三种日历视图自由切换，支持日程卡片拖拽移动、拉伸调整时长。可配置日、周、月循环重复日程及定时提醒，支持日历空白区域快捷新建日程。鼠标悬浮卡片可预览日程详情，支持日程分类配色、过期状态标记，可通过多条件筛选快速查询对应日程，适配个人多样化时间管理场景。

**技术要求**：Go Gin实现日程增删改查、重复规则解析、提醒配置、数据筛选接口；Vue3完成日历动态渲染、拖拽交互、视图切换等高难度前端功能；SQLite存储日程及分类数据；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接运行。
