在线拖拽式流程审批系统

**总体功能**：针对企业轻量化办公审批场景，搭建可视化流程配置平台，支持自定义审批流程、单据提交、节点流转、状态跟进，实现全流程线上自动化审批。

**详细功能需求**：前端画布支持拖拽节点、连线搭建审批流程，可自定义审批人员、流转条件、节点属性；支持请假、报销、通用申请单据线上提交；实现审批进度可视化、节点状态实时更新，支持审批驳回、撤回、加签操作，支持流程模板保存、复用与编辑。

**技术要求**：Go Gin开发轻量化流程引擎、权限校验、流转规则、审批记录接口；Vue3实现画布拖拽、节点联动、动态表单渲染等高难度交互；SQLite存储流程模板、审批单据及流转日志；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接运行。
