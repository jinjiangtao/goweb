适配线上学习刷题场景，搭建完整题库管理与在线刷题系统，实现题库维护、智能组卷、实时判分、错题归集与数据统计，形成闭环线上刷题学习体系。

**详细功能需求**：后台支持批量新增、编辑、删除单选、多选、判断题库，可录入题目解析内容。前端支持随机组卷、顺序刷题，实时缓存答题进度防止数据丢失。答题提交后系统即时自动判分、展示题目解析，自动归集错题形成错题集。可视化统计刷题正确率、完成进度，支持历史答题记录回溯查看，助力用户查漏补缺。

**技术要求**：Go Gin实现题库管理、智能组卷、自动判分、数据统计接口；Vue3实现动态答题页面、答案联动校验、进度缓存、错题切换等高交互；SQLite存储题库、答题记录、错题数据；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接编译运行。
