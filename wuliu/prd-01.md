模拟物流订单全流程运输场景，开发物流轨迹可视化查询系统，通过时间线动态展示物流节点状态，实现运输进度实时更新、轨迹追溯与异常监控。

**详细功能需求**：后台支持录入物流订单基础信息、运输节点与运输状态，可随时更新物流进度。前端以时间线动态渲染物流轨迹，不同状态节点自动变色区分，进度条实时加载更新。支持单号精准检索、节点悬浮预览详情，可标记异常物流节点，支持历史运输轨迹回溯查询，实现物流进度可视化管控。

**技术要求**：Go Gin实现物流订单、轨迹节点数据新增、更新、查询接口；Vue3实现时间线动态渲染、进度联动、状态切换等高难度可视化交互；SQLite存储物流订单与轨迹数据；后端代码存放于 server 目录，前端代码存放于 web 目录，项目可直接编译运行。
