一、项目背景
开发一个企业知识库系统，帮助团队沉淀文档、经验、规范等知识资产。第一阶段聚焦核心功能：文档管理、分类组织、用户认证、草稿/发布机制。系统采用前后端分离架构，后端接口服务放在 server 目录，后台管理界面放在 admin 目录。
二、用户角色
角色 说明
读者（未登录） 浏览文章列表、阅读文章详情，不能增删改
作者（已登录） 创建、编辑、删除自己的文章，可存草稿或发布
管理员 拥有所有权限，管理分类、删除任意文章
三、功能需求
3.1 用户认证
注册：
· 通过用户名、密码、昵称进行注册
· 用户名必须唯一
· 注册成功后引导至登录页
登录：
· 通过用户名+密码登录
· 登录后保持登录状态
· 顶部导航显示用户昵称
权限：
· 未登录用户只能浏览
· 作者仅能操作自己的文章
· 管理员可操作所有文章和管理分类
3.2 分类管理（仅管理员）
分类列表：
· 展示所有分类，位于导航栏
分类维护：
· 新增分类（名称、排序号）
· 编辑分类（名称、排序号）
· 删除分类（分类下已有文章则不可删除，需先处理文章）
3.3 文章管理
文章列表：
· 按发布时间倒序展示所有已发布文章
· 显示：标题、分类、发布时间、作者昵称
· 支持分页加载
· 登录用户可见「新建文章」入口
文章详情：
· 展示完整内容：标题、分类、发布时间、作者、正文
· 作者本人或管理员可见「编辑」「删除」按钮
创建文章：
· 填写：标题（必填）、分类（必填）、正文（必填）
· 可选择：直接发布 或 存为草稿
· 提交后跳转至文章列表
编辑文章：
· 回填所有已有信息
· 可修改标题、分类、正文、状态（草稿↔发布）
· 提交后更新并跳转
删除文章：
· 二次确认后软删除（列表不再显示）
我的文章：
· 展示当前用户创建的所有文章（含草稿）
· 草稿有特殊标识
3.4 搜索功能
· 顶部导航栏提供搜索框
· 按文章标题模糊搜索
· 结果以列表形式展示
四、项目结构
```
server/                    # 后端接口服务
admin/                     # 后台管理前端
```
五、页面清单
页面 路径 目录位置
首页（文章列表） / admin
文章详情页 /article/:id admin
创建文章页 /article/create admin
编辑文章页 /article/edit/:id admin
我的文章页 /my-articles admin
分类管理页 /categories admin
登录页 /login admin
注册页 /register admin
六、验收标准
1. 未登录用户可以浏览文章列表和阅读详情
2. 用户可以注册账号并登录系统
3. 登录后可以创建文章，选择分类，选择发布或存草稿
4. 作者只能编辑和删除自己创建的文章
5. 管理员可以管理分类（增删改），分类下有文章时不可删除
6. 管理员可以删除任意文章
7. 首页只展示「已发布」的文章
8. 「我的文章」展示自己所有文章（含草稿）
9. 搜索框按标题搜索文章
10. 页面刷新后登录状态保持
