## 任务：为知识库系统增加「版本对比」和「Markdown支持」两个功能

## 现有系统情况：
- 已有功能：用户注册登录、文章增删改查、分类管理、草稿/发布状态
- 技术栈：Go + Gin + GORM + SQLite，Vue3 + Vite（纯手写样式）
- 项目结构：server/（后端API）、admin/（前端）

## 功能需求：


### 第一部分：Markdown 支持

#### 1.1 编辑器升级
- 将文章创建/编辑页面的普通多行文本框升级为 Markdown 编辑器
- 编辑器支持基础 Markdown 语法：
  - 标题（# ## ###）
  - 粗体（**文本**）
  - 斜体（*文本*）
  - 链接（[文字](url)）
  - 图片（![alt](url)）
  - 代码块（```语言 代码 ```）
  - 行内代码（`代码`）
  - 引用（> 文本）
  - 列表（- 或 1.）
  - 分割线（---）

#### 1.2 实时预览
- 编辑器区域采用左右分栏布局：
  - 左侧：编辑区（输入 Markdown 源码）
  - 右侧：预览区（实时渲染 HTML）
- 同步滚动：编辑区滚动时，预览区同步滚动（反之亦然）
- 预览区实时更新，无需点击任何按钮

#### 1.3 文章详情页渲染
- 文章详情页将存储的 Markdown 源码渲染为 HTML 展示
- 代码块需支持语法高亮（使用 highlight.js 或 Prism.js）
- 表格、图片、链接等正常渲染

#### 1.4 版本对比支持 Markdown 渲染
- 版本对比页面中，左右两栏展示 Markdown 渲染后的 HTML（Diff 高亮）
- 纯文本对比和渲染后对比可切换


### 第二部分：版本对比（核心难点）

#### 2.1 版本历史列表
- 文章详情页底部显示「版本历史」区域
- 列表展示：版本号（V1、V2、V3…）、保存时间、状态标签（已发布/草稿）
- 每篇文章最多保留 50 个版本

#### 2.2 版本详情查看
- 点击「查看此版本」弹窗展示该版本完整内容（只读）
- 展示版本号、保存时间、状态标签

#### 2.3 版本对比（核心）
**对比选择**：
- 在版本历史列表中勾选两个版本进行对比
- 或默认选中「当前版本 vs 上一个版本」
- 支持切换对比的两个版本

**对比维度**：
| 对比项 | 展示方式 |
| :--- | :--- |
| 标题 | 显示旧标题 → 新标题，变化部分高亮 |
| 分类 | 显示旧分类 → 新分类 |
| 正文 | 逐行对比，显示增删改 |

**正文对比算法**：
- 基于行级别的差异对比
- 新增行：绿色背景 + 前置 +
- 删除行：红色背景 + 删除线 + 前置 -
- 修改行：黄色背景（拆分为删除+新增）
- 未变化行：正常显示

**对比展示方式**：
- 左右两栏布局：左旧右新
- 或上下逐行对比（推荐，更清晰）
- 切换展示模式

**无差异处理**：
- 显示「两个版本内容完全一致」

#### 2.4 版本回滚
- 在版本详情页或对比页点击「回滚到此版本」
- 二次确认后执行回滚
- 回滚操作本身生成一个新版本（记录「回滚到 V3」）
- 回滚成功后跳转到文章详情页

**回滚冲突处理**：
- 文章被他人修改时提示“文章已被修改，请刷新后重试”
- 目标版本已被清理时提示“该版本已不存在”

#### 2.5 版本清理
- 自动清理：超过 50 个版本时删除最早的
- 管理员可手动删除任意版本（当前版本不可删除）


### 第三部分：前后端接口要求

#### 后端新增接口

| 功能 | 说明 |
| :--- | :--- |
| 保存版本 | 每次保存文章时自动生成版本快照（含标题、正文Markdown原文、分类） |
| 版本列表 | 获取某篇文章的所有版本（分页） |
| 版本详情 | 获取某个版本的完整内容 |
| 版本对比数据 | 获取两个版本的差异数据（标题、分类、正文的增删改行列表） |
| 版本回滚 | 将文章内容替换为目标版本，并生成回滚记录 |
| 版本删除 | 管理员删除指定版本 |

#### 前端新增/修改页面

| 页面/组件 | 位置 | 说明 |
| :--- | :--- | :--- |
| Markdown 编辑器 | 创建/编辑文章页 | 左右分栏：编辑+实时预览，同步滚动 |
| 文章详情页 | 原有页面修改 | 使用 Markdown 渲染引擎展示正文 |
| 版本历史组件 | 文章详情页底部 | 折叠展示版本列表 |
| 版本详情弹窗 | 独立弹窗 | 只读展示某版本渲染后的内容 |
| 版本对比页面 | /compare/:id | 左右/上下对比两个版本的差异 |


### 第四部分：技术要求

#### Markdown 编辑器
- 使用轻量级 Markdown 解析库（如 `marked.js` 或 `markdown-it`）
- 语法高亮使用 `highlight.js` 或 `Prism.js`
- 不引入重型富文本编辑器（如 TinyMCE、Quill）
- 同步滚动使用 `scroll` 事件监听和比例计算

#### 版本对比算法
- 使用最长公共子序列（LCS）算法计算行级差异
- 纯 Go 实现，不依赖第三方库
- 时间复杂度 O(n×m)，n 和 m 为两个版本的行数（实际场景行数有限，性能可接受）

#### 性能要求
- 版本对比响应时间 < 500ms
- 编辑区输入和预览渲染无明显卡顿
- 版本列表支持分页（每页 20 条）


### 第五部分：数据模型新增

**版本表**：
- ID、文章ID、版本号
- 标题快照
- 正文快照（Markdown 原文）
- 分类ID快照
- 状态快照（draft/published）
- 创建时间
- 创建人ID
- 回滚标记（是否为回滚操作产生的版本）
- 回滚来源版本号（如果是回滚产生的）
